# Handwritten Digit Recognition

A Convolutional Neural Network (CNN) that recognizes a single handwritten digit (0–9) from an uploaded image. The project uses the MNIST dataset and includes a Streamlit web interface for interactive predictions.

## Project Highlights

- Trained a CNN on the MNIST handwritten-digit dataset.
- Achieved **99.14% test accuracy** in the recorded evaluation.
- Upload an image (`PNG`, `JPG`, or `JPEG`) and receive a predicted digit.
- View the processed 28 × 28 image supplied to the model.
- View prediction probabilities for all ten digit classes.
- Includes image preprocessing to help isolate a digit from common photo backgrounds.

> Note: The reported 99.14% is the model's test-set accuracy on MNIST. It is not a guarantee of the same accuracy on photos of handwritten digits taken with a phone. Real-world photos may need different preprocessing.

## Demo Features

1. Upload a photo containing one handwritten digit.
2. The app preprocesses the image for the model.
3. The CNN predicts a digit from 0 to 9.
4. The interface displays the prediction, confidence score, processed model input, and class probabilities.

## Setup

### 1. Clone the repository

```bash
git clone https://github.com/YOUR-GITHUB-USERNAME/YOUR-REPOSITORY-NAME.git
cd YOUR-REPOSITORY-NAME
```

Replace the URL and repository name with your actual GitHub repository.

### 2. Create and activate a virtual environment

Windows PowerShell:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

If PowerShell blocks activation, you can use Command Prompt instead:

```bat
.venv\Scripts\activate.bat
```

### 3. Install dependencies

```bash
python -m pip install --upgrade pip
pip install -r requirements.txt
```

### 4. Run the app

```bash
streamlit run app.py
```

Streamlit will print a local URL in the terminal, usually `http://localhost:8501`.

## Model Evaluation

The recorded MNIST test accuracy is **99.14%**. Evaluation outputs are saved in the `reports/` directory when generated by the training script.

The model predicts one digit per image. It is not designed to read multi-digit numbers such as `2026` as a sequence.

## Tips for Better Predictions

- Upload an image containing one digit.
- Make sure the digit is clear and large enough.
- Avoid strong shadows, blur, and clutter.
- Check the displayed **Processed Model Input**. If the digit is cropped incorrectly or notebook lines remain, the prediction may be unreliable.
- The model was trained on MNIST, so photographs of real paper can differ from the training data.
